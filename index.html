SOBRE O PROJETO

O que é o CurrencyFlow?

O CurrencyFlow é uma aplicação web desenvolvida para tornar a conversão de moedas mais simples, rápida e intuitiva. Com uma interface moderna e funcional, a plataforma permite converter valores entre diferentes moedas, consultar cotações atualizadas por meio de uma API externa e acompanhar o histórico das conversões realizadas.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, aplicando conceitos de manipulação do DOM, consumo de APIs, armazenamento local com LocalStorage e validação de dados. Moedas disponíveis: Real Brasileiro (BRL), Dólar Americano (USD), Euro (EUR), Libra Esterlina (GBP) e Bitcoin (BTC).
