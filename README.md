# 💱 CurrencyFlow — Conversor de Moedas

O **CurrencyFlow** é uma aplicação web desenvolvida para tornar a conversão de moedas mais simples, rápida e intuitiva.

Com uma interface moderna e responsiva, a aplicação permite converter valores entre diferentes moedas, consultar cotações atualizadas por meio de uma API externa e acompanhar o histórico das conversões realizadas.

## 🚀 Funcionalidades

- Conversão entre Real Brasileiro (BRL), Dólar Americano (USD), Euro (EUR), Libra Esterlina (GBP) e Bitcoin (BTC).
- Consulta de cotações por meio de API externa.
- Atualização automática dos valores convertidos.
- Alternância entre moedas de origem e destino.
- Exibição de cotações rápidas.
- Histórico das conversões realizadas.
- Armazenamento do histórico utilizando LocalStorage.
- Opção para limpar o histórico com confirmação.
- Interface responsiva para diferentes tamanhos de tela.
- Tratamento de erros e validação de dados.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação da aplicação.
- **CSS3:** estilização, layout responsivo e efeitos visuais.
- **JavaScript:** lógica de conversão, manipulação do DOM e interatividade.
- **AwesomeAPI:** consulta de cotações de moedas.
- **LocalStorage:** armazenamento local do histórico de conversões.

## 📡 API utilizada

O projeto utiliza a [AwesomeAPI](https://docs.awesomeapi.com.br/api-de-moedas) para obter as cotações das moedas em tempo real.

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server.
4. Utilize o conversor diretamente no navegador.

É necessária conexão com a internet para consultar as cotações da API.

## 🎯 Objetivo do projeto

O CurrencyFlow foi desenvolvido como projeto prático de estudos em desenvolvimento web, com o objetivo de aplicar conhecimentos em HTML, CSS e JavaScript, especialmente na manipulação do DOM, consumo de APIs, validação de dados e armazenamento local.
